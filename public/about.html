CDAC-Smart Parking System


An IoT-based Smart Parking System designed for real-time parking slot monitoring, online booking, and sensor-driven occupancy management.


Smart • Real-Time • Sensor-Based • User-Friendly

Smart Parking Overview

The CDAC Smart Parking System is an IoT-based parking management platform developed for
real-time monitoring and booking of parking slots. The system integrates NodeMCU ESP8266,
ultrasonic sensors, cloud communication through ThingSpeak, a Node.js backend,
and MongoDB database services to provide accurate parking slot availability
and booking management. Users can monitor slot status, reserve parking spaces, and receive live updates,
while administrators can manage system status and bookings through a dedicated dashboard.
The system reduces manual effort and improves parking efficiency using sensor-driven automation and real-time monitoring.


Real-time Slot Monitoring

Monitor parking slot availability instantly using live sensor updates and dashboard monitoring.

Online Slot Booking

Reserve available parking slots through the web platform with real-time availability status.

Sensor-driven Detection

Ultrasonic sensors automatically detect vehicle presence and update slot occupancy.

Live Status Updates

Receive instant slot information through real-time cloud and database synchronization.
